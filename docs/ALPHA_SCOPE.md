# Invite-only Alpha scope

## Included

- Invite-only reader accounts
- Secure cross-device persistence
- Book records and reading states
- The core shelf
- Private reflections
- One private photograph per book
- Import from the `marginalia.v0.1` browser prototype
- Complete HTML, JSON, and photograph export
- Print-to-PDF support
- Account recovery and deletion
- Accessible, responsive Marginalia visual system

## Prepared in the architecture, not enabled in Alpha

- Patron entitlements and storage quotas
- Multiple photographs per book
- Advanced tags and search
- Revision history
- Annual activity records
- Billing integration

## Deliberately deferred

- Feeds, followers, direct messaging, and recommendation algorithms
- Camera or barcode library scanning
- Collaborative print-publisher integration
- Publication-quality editorial exports
- Custom shelf artifacts and ephemera
- *A Year Among the Margins* annual volume
